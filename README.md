# my_css_workshop

CSS workshop: an article about Sass converted to HTML (`css_workshop.html`)
and styled with an external style sheet (`css/css_workshop.css`).

Open the page in the browser:

<https://htmlpreview.github.io/?https://github.com/jromanovs/my_css_workshop/blob/main/css_workshop.html>

## Steps

1. The article as plain HTML, no styles, built from a basic HTML5 template.
2. Styles in `css/css_workshop.css`, linked from the page.
